Multi-Timer & Clock Suite
A responsive, single-page web application featuring a live local digital clock and three independent, customizable task-labeled timers with audio alarms. Built with HTML5, Tailwind CSS, FontAwesome, and the Web Audio API.

Features
Live Local Clock: Displays current local time (12-hour format with AM/PM), live seconds, full date, and detected time zone.

Three Independent Timers:

Timer 1 & 2: Pre-configured 1-minute countdown timers.

Timer 3: Fully customizable duration timer (minutes and seconds).

Task Labeling: Custom text input for naming each timer (e.g., Sprint, Meeting, Tea Break) with quick-select preset tags.

Local Storage Persistence: Saved timer labels persist across page reloads.

Web Audio API Synthesizer: Generates distinct harmonic audio chimes without external sound file dependencies.

Dedicated Alarm Controls: Includes an animated Stop Ringer button to silence alarms independently without resetting countdown state.

Theme Support: Integrated Dark and Light mode toggle.
